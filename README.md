# 走進孔廟 — 特殊門票紀念網頁

臺南孔廟特殊門票（紀念品）掃碼／NFC 感應後開啟的網頁。純靜態網站，無後端、無資料庫，
與姊妹專案 [kongmiao-omamori](https://github.com/Peggy2005/kongmiao-omamori)（NFC 匾額平安符）
共用同一套視覺語言（磚紅／金色配色、Noto Serif TC、左下角禮虎小動畫）。

## 頁面流程

1. **入口動畫**（僅首次進站播放，可點右上角「略過動畫」跳過）
   紅磚牆一塊塊消失 → 廟門緩緩開啟 → 窗花一片片拼合成形 → 淡出進入主站。
   看過一次後會記在 `localStorage`，下次造訪不會重播；頁尾有「重新觀看開場動畫」可手動重播。
   `prefers-reduced-motion` 開啟時直接略過動畫。
2. **抽籤與解籤**：仿姊妹站的抽籤互動（1.1 秒抽籤動畫＋星等＋解籤文字），可存成圖片分享。
3. **許願牌**：遊客可寫下願望「掛上許願牌」。願望只存在使用者自己手機的 `localStorage`，
   不會上傳到任何伺服器，也不會被其他人看到——這是純靜態架構下的取捨，如果之後要做
   「所有遊客共同的許願牆」，需要另外加後端／資料庫。
4. **建築特色**：紅牆宮牆、泮宮石坊、大成坊、大成門、大成殿、明倫堂、文昌閣、燕尾花格窗。
5. **孔廟故事**：大成殿八方清代御匾（康熙「萬世師表」到光緒「斯文在茲」），逐一附上出處
   經典與白話解釋，以及當代元首持續獻匾的後續故事。
6. **在地連結歷史脈絡**：1665 陳永華建廟興學、全臺首學的由來、與忠義國小百年樹人的緣分、
   海濱鄒魯雅譽。
7. **建議參觀路線**：依建築軸線排出的 10 站參觀順序。
8. **周邊景點指南**：府中街、臺灣文學館、湯德章紀念公園、赤崁樓、大天后宮／祀典武廟、
   忠義國小，各附步行距離。
9. **園區植物小介紹**：中庭老榕樹，以及門前象徵操守／品德／氣節的樟樹、楷樹、楓樹。

## 內容來源

- [臺南孔廟官方網站](https://www.tn-confucius.org.tw)｜建築導覽、孔廟故事（御匾）、參觀資訊
- 國家文化資產網（nchdb.boch.gov.tw）
- 台南旅遊網（twtainan.net）

抽籤／許願內容為本站原創祝福語，並非官方籤詩，僅供互動體驗使用。

## 本機預覽

```bash
cd kongmiao-tour
python3 -m http.server 8936
# 開瀏覽器：http://localhost:8936
```

## 部署

純靜態檔案（`index.html` + `assets/`），可部署到：

- **GitHub Pages**：repo 開 Pages，root 設成此資料夾（或這個 repo 的根目錄）
- **Cloudflare Pages**：`npx wrangler pages deploy .`
- **Zeabur**：當靜態網站部署

部署好網域之後，把網址燒進特殊門票的 NFC 晶片／QR code。
